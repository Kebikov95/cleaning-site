# Чистый Диван — сайт химчистки мягкой мебели

Простой статический сайт (HTML + CSS + JS) для услуги химчистки диванов,
стульев, кресел, ковров и салонов автомобилей. Дизайн в бело-серо-жёлтой
гамме, полностью на русском языке.

## Структура

```
├── index.html        — главная страница (услуги, этапы, о компании, FAQ)
├── prices.html       — расценки по всем услугам
├── contacts.html     — контакты (телефон, Telegram, Instagram) и форма заявки
├── css/style.css     — все стили (переменные в :root — легко менять палитру)
├── js/main.js        — мобильное меню, анимации, обработка формы
└── assets/           — изображения (Unsplash, свободная лицензия) и favicon
```

## Запуск локально

Достаточно открыть `index.html` в браузере. Для локального сервера:

```bash
npm start          # http://localhost:3000
```

## Проверка кода (статический анализ)

```bash
npm install        # один раз, ставит линтеры
npm run lint       # ESLint + Stylelint + html-validate
npm run lint:js    # только JavaScript
npm run lint:css   # только CSS (stylelint + порядок свойств)
npm run lint:html  # только HTML
```
