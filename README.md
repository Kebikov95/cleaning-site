# Fresh Gomel — сайт химчистки мягкой мебели

Простой статический сайт (HTML + CSS + JS) для услуги химчистки диванов,
стульев, матрасов, ковров и салонов автомобилей в Гомеле и Гомельской
области. Дизайн в бело-серо-жёлтой гамме.

## Структура

```
├── index.html        — главная страница (услуги, этапы, о компании, FAQ)
├── prices.html       — расценки по всем услугам
├── contacts.html     — контакты (телефон, Telegram, email, Instagram) и форма заявки
├── css/style.css     — все стили (переменные в :root — легко менять палитру)
├── js/main.js        — мобильное меню, анимации, обработка формы
└── assets/           — изображения (Unsplash / Pexels, свободные лицензии) и favicon
```

## Запуск локально

Достаточно открыть `index.html` в браузере. Для локального сервера:

```bash
npm start          # http://localhost:3000
```

## Проверка кода (статический анализ)

```bash
npm install        # один раз, ставит линтеры
npm run lint       # ESLint + Stylelint + html-validate
npm run lint:js    # только JavaScript
npm run lint:css   # только CSS (stylelint + порядок свойств)
npm run lint:html  # только HTML
```

## Что доделать перед полноценным запуском

1. **Форма заявки работает в демо-режиме**: показывает сообщение об отправке,
   но ни текст, ни приложенные фото никуда не уходят. Для приёма заявок
   подключите сервис форм (Formspree/Web3Forms) или Telegram-бот —
   обычный статический хостинг не умеет принимать POST-запросы.
2. **Публикация**: включите GitHub Pages (Settings → Pages → branch `main`,
   папка `/ (root)`). Sitemap и robots.txt уже настроены под адрес
   `kebikov95.github.io/cleaning-site` — при подключении своего домена
   замените URL в обоих файлах.
3. **SEO**: добавьте сайт в Яндекс.Вебмастер и Google Search Console,
   укажите регион — Гомель.
